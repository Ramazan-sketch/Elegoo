# Инструкция по деплою на Cloudflare Pages

Cloudflare Pages — это отличный бесплатный хостинг. Вот как перенести туда твой проект:

## Шаг 1: Подготовка (GitHub)
Cloudflare Pages лучше всего работает через GitHub.
1. Создай репозиторий на [GitHub](https://github.com).
2. Загрузи туда код этого проекта.

## Шаг 2: Настройка в Cloudflare
1. Зайди в панель управления [Cloudflare](https://dash.cloudflare.com/).
2. В меню слева выбери **Workers & Pages**.
3. Нажми кнопку **Create application**, затем выбери вкладку **Pages**.
4. Нажми **Connect to Git** и выбери свой репозиторий с кодом.

## Шаг 3: Настройки сборки (Build settings)
Cloudflare предложит настройки. Проверь, чтобы они были такими:
*   **Framework preset:** `Vite`
*   **Build command:** `npm run build`
*   **Build output directory:** `dist`
*   **Node.js version:** (если спросит) выбери `18` или выше.

Нажми **Save and Deploy**. Через 1-2 минуты сайт будет доступен по техническому адресу (например, `my-app.pages.dev`).

## Шаг 4: Подключение своего домена
1. Внутри твоего проекта в Cloudflare Pages перейди на вкладку **Custom domains**.
2. Нажми **Set up a custom domain**.
3. Введи свой домен (например, `mysite.com`).
4. **Если твой домен уже в Cloudflare:** Настройки обновятся автоматически.
5. **Если домен у другого регистратора (Reg.ru и т.д.):** Cloudflare даст тебе CNAME-запись. Тебе нужно будет зайти в панель регистратора и добавить её:
    *   **Тип:** CNAME
    *   **Имя:** @ (или твой поддомен)
    *   **Значение:** `название-проекта.pages.dev`

## Почему Cloudflare Pages — это круто?
*   **Бесплатно:** Неограниченный трафик.
*   **Скорость:** Сайт открывается мгновенно по всему миру.
*   **SSL:** Безопасное соединение (замочек) подключается автоматически.
